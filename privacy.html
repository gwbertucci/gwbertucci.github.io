Landfall Hermes Access

Privacy policy

Effective 1 November 2026

Landfall Hermes Access is a personal-use application operated solely for the owner of the gwbertucci GitHub account. It is not a public service.

Data accessed and used

With the owner's Google authorization, the application accesses relevant Google Calendar information, including calendar and event details such as titles, dates, times, descriptions, locations and attendees. It uses this information for the owner's scheduling, reminders and personal-assistant tasks. Event creation and changes are limited by the granted permissions and the owner's instructions.

With Gmail authorization, the owner's Elena assistant can search messages and read relevant message headers, labels, snippets and text, including sender, recipients, subject and date. With separately authorized compose permission, Elena can also save unsent plain-text drafts, including recipients, subject and body, for the owner to review and send manually. This supports the owner's correspondence, deadline reviews and assigned personal-assistant tasks. Attachment names and types may be displayed. Gmail's message responses can include embedded attachment data; the application discards it rather than opening, analyzing, saving or passing it to AI providers through these tools. Separate attachment retrieval is not enabled. Google's compose permission also permits sending, but this application's tools expose no email-sending interface. They create unsent drafts and do not change labels, mark messages read, archive or delete messages. Drafts remain in the owner's Gmail account; private local retry receipts contain identifiers and content hashes, not draft bodies.

Storage and processing

Credentials remain on the owner's controlled Hermes host and are not published on this website or in its public repository. Relevant calendar information, email content or derived task context may be processed by the owner's configured AI providers and assistant services, including private Discord conversations or owner-selected Notion records, solely to provide the requested personal-assistant functionality. Private mail is not automatically copied into Notion. Google access tokens are not supplied as model context.

Google user data is not sold, made public, or used for advertising. This application does not use Google user data to train general-purpose AI models. Its use and transfer of Google API data follow the Google API Services User Data Policy, including its Limited Use requirements.

Retention and owner control

Records and backups are retained as needed for the owner's personal-assistant work and can be removed by the owner. Access can be revoked at any time through Google Account connections. Revocation stops future authorized API access; it does not automatically erase previously saved notes, logs or backups, which the owner manages separately.

This public website

These static pages contain no sign-in form, advertising or application analytics. They do not collect calendar data, email messages or credentials. They are hosted on GitHub Pages; website hosting is subject to GitHub's privacy practices.

Contact and changes

The owner can be contacted using the support email shown on Google's consent screen. This policy will be updated before materially different Google-data features are enabled.
