Landfall Hermes Access

Privacy policy

Effective 1 November 2026

Landfall Hermes Access is a personal-use application operated solely for the owner of the gwbertucci GitHub account. It is not a public service.

Data accessed and used

With the owner's Google authorization, the application accesses relevant Google Calendar information, including calendar and event details such as titles, dates, times, descriptions, locations and attendees. It uses this information for the owner's scheduling, reminders and personal-assistant tasks. Event creation, changes and deletion are limited by the granted permissions and the owner's instructions. Gmail access is outside this Calendar setup.

Storage and processing

Credentials remain on the owner's controlled Hermes host and are not published on this website or in its public repository. Relevant calendar information or derived task context may be processed by the owner's configured AI providers and assistant services, including private Discord conversations or owner-selected Notion records, solely to provide the requested personal-assistant functionality. Google access tokens are not supplied as model context.

Google user data is not sold, made public, or used for advertising. This application does not use Google user data to train general-purpose AI models. Its use and transfer of Google API data follow the Google API Services User Data Policy, including its Limited Use requirements.

Retention and owner control

Records and backups are retained as needed for the owner's personal-assistant work and can be removed by the owner. Access can be revoked at any time through Google Account connections. Revocation stops future authorized API access; it does not automatically erase previously saved notes, logs or backups, which the owner manages separately.

This public website

These static pages contain no sign-in form, advertising or application analytics. They do not collect calendar data or credentials. They are hosted on GitHub Pages; website hosting is subject to GitHub's privacy practices.

Contact and changes

The owner can be contacted using the support email shown on Google's consent screen. This policy will be updated before materially different Google-data features are enabled.
