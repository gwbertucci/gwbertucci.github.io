Landfall Hermes Access

Personal automation tools used only by their owner. This application is not offered to the public and has no public sign-up.

What the application does

Landfall connects the owner's Elena personal assistant to Google Calendar so she can review commitments, identify scheduling conflicts, prepare reminders, and create or update events within the owner's authorized instructions. When separately authorized, Elena can also search and read Gmail messages and prepare unsent drafts to help with correspondence, deadlines and assigned tasks. Actual access depends on the permissions granted through Google.

The application is operated by the owner of the gwbertucci GitHub account. Its assistants run on the owner's controlled Hermes host. This website contains public app information only; it does not handle Google sign-in or store calendar information, email messages or access tokens.

Privacy and control

Read the privacy policy for details of data access, storage, processing and revocation. Google access can be withdrawn through Google Account connections.

Gmail tools support reading and creating unsent drafts for the owner to review and send manually. Google's compose permission also permits sending, but this application's tools expose no email-sending interface. They do not change labels, mark messages read, archive or delete mail. This setup does not open or save attachments. Google Calendar event changes remain subject to the owner's instructions.

Personal-use application. Support contact: the owner email displayed on the Google consent screen.
