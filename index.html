Landfall Hermes Access

Personal automation tools used only by their owner. This application is not offered to the public and has no public sign-up.

What the application does

Landfall connects the owner's Hermes assistants to Google Calendar so they can review commitments, identify scheduling conflicts, prepare reminders, and create or update events within the owner's authorized instructions. Actual access depends on the permissions granted through Google.

The application is operated by the owner of the gwbertucci GitHub account. Its assistants run on the owner's controlled Hermes host. This website contains public app information only; it does not handle Google sign-in or store calendar information or access tokens.

Privacy and control

Read the privacy policy for details of data access, storage, processing and revocation. Google access can be withdrawn through Google Account connections.

Gmail functionality is not included in this Calendar setup. Adding it would require separate authorization and an updated description of its data use.

Personal-use application. Support contact: the owner email displayed on the Google consent screen.
